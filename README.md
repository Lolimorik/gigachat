# README для gigachat_v3.py

Этот скрипт представляет собой реализацию автономного AI-агента с расширенными возможностями управления системой. Основная цель агента — выполнять задачи пользователя полностью автоматически, используя различные встроенные инструменты.

## Описание проекта

Проект предназначен для автоматизации различных задач, связанных с управлением файлами, выполнением системных команд, обработкой чисел и взаимодействием с пользователем. Скрипт позволяет:

- Выполнять математические операции
- Управлять файловой системой
- Выполнять системные команды в терминале
- Предоставлять помощь пользователю в решении разнообразных задач

## Инструменты и возможности

### Работа с временем
- Получение текущего времени в формате ЧЧ:ММ:СС

### Математические операции
- Сложение двух чисел (целых или дробных)

### Управление файлами
- Просмотр списка файлов и папок с подробной информацией
- Создание пустого файла
- Чтение содержимого файла
- Запись текста в файл (перезапись существующего содержания)

### Выполнение системных команд
- Выполнение любой команды в терминале с возможностью вывода результата

### Взаимодействие с пользователем
- Возможность приостановки выполнения для получения дополнительной информации от пользователя
- Поддержка основных команд для взаимодействия с пользователем

## Пример использования

### Установка зависимостей
```bash
pip install dotenv gigachat
```

### Запуск скрипта
```bash
python gigachat_v3.py
```

### Основные команды
```
\\history - просмотр истории сообщений
\\help - справочная информация по доступным командам
\\exit - завершение работы программы
```
