# Сортировки в Python

В этой папке собраны реализации различных алгоритмов сортировки на языке Python:

- **Bubble Sort** (`bubble_sort.py`) — сортировка пузырьком
- **Quick Sort** (`quick_sort.py`) — быстрая сортировка
- **Selection Sort** (`regular_sort.py`) — сортировка выбором

Каждый файл содержит реализацию соответствующего алгоритма и простой пример использования. Вы можете открыть эти файлы и протестировать их работу, используя различные входные данные.

Если у вас есть вопросы или предложения, не стесняйтесь обращаться!
