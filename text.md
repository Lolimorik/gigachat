# Методичка по функциям Python: `print()` и `input()`

## 📌 Описание функций

### Функция `print()`
Функция вывода данных на экран.

**Синтаксис:**
```python
print(*objects, sep=' ', end='\n', file=sys.stdout)
```

- **objects** — объект или последовательность объектов, выводимых на экран.
- **sep** — разделитель между объектами (по умолчанию пробел).
- **end** — символ, завершающий строку (по умолчанию новая строка).
- **file** — файловый объект, куда направляется вывод (по умолчанию стандартный поток вывода sys.stdout).

**Примеры использования:**

```python
# Простой вывод строки
print("Привет!")

# Несколько аргументов через запятую
print("Привет", "мир", "от", "Python")

# Разделитель чисел точкой с запятой
print(1, 2, 3, sep=";")

# Без перехода на новую строку
print("Привет", end=" ")
print("Мир!")
```

### Функция `input()`
Функция считывания данных с клавиатуры.

**Синтаксис:**
```python
input([prompt])
```

- **prompt** — необязательное сообщение, отображаемое пользователю перед вводом.

**Примеры использования:**

```python
# Обычный ввод строки
name = input("Ваше имя? ")

# Ввод числа
age = int(input("Сколько Вам лет? "))

# Сообщение при вводе
print("Спасибо за участие!")
answer = input("Хотите ли вы попробовать еще раз? (да/нет)")
```

### Уровень 3: Продвинутый

5. **Задание №5:** Реализуйте калькулятор, принимающий три числа и выполняющий арифметические операции (+,-,* и /). Результат должен выводиться с двумя знаками после запятой.     
   ```python
   num1 = float(input("Первое число: "))
   operation = input("Операция (+, -, *, /): ")
   num2 = float(input("Второе число: "))

   if operation == '+':
       result = num1 + num2
   elif operation == '-':
       result = num1 - num2
   elif operation == '*':
       result = num1 * num2
   elif operation == '/':
       result = num1 / num2
   else:
       print("Неверная операция!")
       exit()

   print(f"Результат: {result:.2f}")
   ```

6. **Задание №6:** Пользователь вводит целое число. Программа проверяет четность введенного числа и выводит соответствующее сообщение («четное» или «нечетное»).
   ```python
   number = int(input("Введите число: "))

   if number % 2 == 0:
       print("Число четное")
   else:
       print("Число нечетное")
   ```
